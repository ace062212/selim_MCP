# 01. 시스템 구성

## 한눈에 보기

```
                         ┌──────────────── 앱 서버 (1대) ────────────────┐
사용자 브라우저 ─────────→ │ /            프론트 (front/ 빌드 결과물)        │
관리자 브라우저 ─────────→ │ /admin       관리자 화면 (같은 빌드, 경로만 다름)  │
                         │ /api/...     키 발급·인증·관리자 API (WAS)       │ ──→ PostgreSQL
Claude Code / Desktop ──→ │ /mcp         MCP 엔드포인트 (Streamable HTTP)   │ ──→ 사내 시스템, 외부 API
Cursor                   └───────────────────────────────────────────────┘
                                          │
                                          └──→ 메일 발송 (써팀 SMTP 또는 AWS SES)
```

| 구성 요소 | 역할 | 비고 |
|---|---|---|
| 프론트 | 사용자 화면(`/`), 관리자 화면(`/admin`) | 정적 파일. 앱 서버나 nginx가 같이 내려줌 |
| WAS | 인증번호 발송·확인, 키 발급·조회, 도구 설정, 관리자 기능 | `/api/...` |
| MCP 서버 | 클라이언트가 접속해 도구 목록 조회·도구 호출 | `/mcp`. API 키 검증 로직을 WAS와 공유하므로 처음엔 같은 앱에 둠 |
| DB | 사용자, 키, 인증번호, 도구 설정, 호출 기록 | PostgreSQL. 스키마는 `sql/` |
| 메일 | 인증번호 발송 | 발송 수단은 미정 (아래 참고) |

## 처음엔 앱 1개 + DB 1개

- 프론트는 빌드하면 HTML/JS 파일이라 별도 서버가 필요 없음.
- MCP도 결국 HTTP 경로 하나(`/mcp`)라 WAS 안에 같이 둘 수 있음.
- MCP 호출량이 많아지면 그때 MCP 서버만 분리.

## 배포 시 주의

- `/admin`으로 직접 접속해도 `index.html`을 내려주도록 설정해야 함 (SPA fallback).
- `/mcp`, `/api`는 HTTPS 필수 (API 키가 헤더로 오감).

## 메일 발송 수단 (미정)

| 방법 | 비용 | 메모 |
|---|---|---|
| 써팀 SMTP 릴레이 | 무료 | 회사 IT에 SMTP 정보 요청 필요. selim.kr SPF가 이미 써팀(`_spf.sirteam.net`)으로 설정돼 있어 도착률 유리 |
| AWS SES | 1,000통당 약 $0.10 | SPF/DKIM DNS 레코드 추가 필요 |

인증 메일은 HTML 템플릿(회사 로고, 브랜드 색)으로 보낼 수 있음.

## 환경변수 (예정)

| 이름 | 용도 |
|---|---|
| `DATABASE_URL` | PostgreSQL 접속 정보 |
| `API_KEY_ENC_KEY` | API 키 원문 암호화용 AES-256 키 (`api_keys.key_enc`) |
| `OTP_PEPPER` | 인증번호 해시용 비밀값 |
| `SESSION_SECRET` | 세션 토큰(JWT) 서명 키 |
| `SMTP_*` 또는 `AWS_SES_*` | 메일 발송 |

비밀값은 저장소에 올리지 않음 (`.env`는 `.gitignore`에 포함).
